TOKEN RADAR

Pre-token protocols, ranked by what a launch would be worth — and how to farm each one.

How to read this board

Implied value = TVL × category multiple × growth × age × chains. The multiple is the median market-cap/TVL of token-bearing protocols in the same category (overall median 0.2138 when a category has too few). Growth is the 7-day TVL change damped by half; age rewards protocols that ran longer with no token; each chain adds 2%. A protocol records no token in the snapshot — that is not proof it has none. Rows marked TOKEN TRADES were checked against the live market on 14 Nov 2026 and their token already trades; they stay on the board because the watchlist requires them, but the launch thesis is dead for them. Two more rows were left out entirely for the same reason — see the corrections note at the bottom. Rank is the model’s claim, never a promise.

Data corrections

Two protocols were left out of this board because their token already trades. The snapshot records no token for them, so this is a data gap, not a model choice.

    Method

    Snapshot: DefiLlama protocol data, 758 protocols at or above $5M TVL, fetched 14 Nov 2026. Watchlist: 40 protocols at or above the $50M floor that record no token and are not a wrapped, staked or bridged product. Board: 196 rows — the whole watchlist plus every other rankable protocol. Implied value is computed from the snapshot’s own figures only; no protocol name is special-cased in the model. Farm plans are built from each protocol’s category, chains, TVL and age, with concrete costs ($50–$200 of capital, a few dollars of gas) and a 4–8 week hold. Model version radar-2.

TOKEN RADAR

Every pre-token protocol in the snapshot, ranked by what its launch would be worth — and how to farm it.

VALUE MODEL

Implied value = TVL × category multiple (median mcap/TVL of token-bearing protocols in the same category) × growth × age × chains. All inputs come from the snapshot itself — no hardcoded list of names.

WHAT COUNTS

Only protocols that record no token and are not a wrapped, staked or bridged product of a token that trades. A protocol on this board may still have a token its record does not carry.

READ THIS

An implied value is this entry's own claim, never make.fun's. It does not predict whether or when a token is issued.
